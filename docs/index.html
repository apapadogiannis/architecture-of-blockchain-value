1. More capabilities, and how strongly they reinforce one another

A blockchain delivers K capabilities (services). Each one is worth the same on its own, and every pair adds a bonus of size η because the two can be used together. Value then grows with the number of pairs, which is why it curves upward.

V = φ u N(u) · [ K + η · K(K − 1) / 2 ]

Equation (14). The chart shows the bracket, that is, value with φ = u = N = 1.

2. How value grows with the number of users

The term u N(u) in the equation above depends on how users connect. Three classical laws give three very different curves. The paper associates single-capability networks mainly with Metcalfe, multi-capability networks with a move from Metcalfe toward Reed, and meta-capability networks with Reed.

What this is, and is not. The model is stylized. The values η = 0.5 and η = 0.75 used in the paper are illustrations, not estimates, and the units of users and value are arbitrary. Nothing on this page values a specific network or token.
